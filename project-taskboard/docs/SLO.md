# SLO - TaskBoard

## SLI
אחוז הבקשות ל-API שמחזירות תשובה שאינה 5xx, נמדד מ-`http_requests_total` ב-Prometheus:

```promql
1 - sum(rate(http_requests_total{status=~"5.."}[30d])) / sum(rate(http_requests_total[30d]))
```

## SLO
**99.5%** מהבקשות מצליחות, בחלון מתגלגל של **30 ימים**.

## Error budget
- חלון: 30 ימים = 43,200 דקות.
- מותר להיכשל: 100% - 99.5% = 0.5%.
- תקציב: 0.5% × 43,200 = **216 דקות** של שירות לא תקין בחודש.

## מה עושים כשהתקציב נגמר
- עוצרים שחרור פיצ'רים חדשים, ועובדים רק על יציבות עד שהתקציב חוזר.
- כל תקלה שאכלה יותר מ-25% מהתקציב מקבלת postmortem.
